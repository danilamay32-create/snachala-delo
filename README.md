# Сначала дело

Приложение для macOS 12+ (Intel и M1). Пока у незакрытой задачи дедлайн ближе суток,
сайты с сериалами не открываются ни в одном браузере, а плееры (IINA, VLC, Apple TV…) закрываются при запуске.

## Сборка (на любом Маке)

```
xcode-select --install        # один раз, если нет Command Line Tools
./scripts/build.sh
```

Получится `build/SnachalaDelo-0.1.0.pkg` (универсальный, Intel + Apple Silicon) и `build/uninstall.sh`.

## Установка на Мак сестры

1. Скопировать `.pkg` на её Мак.
2. Правый клик → «Открыть» (установщик не подписан, двойной клик macOS не пустит). На macOS 13+ может понадобиться
   «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть».
3. Ввести пароль администратора. В строке меню появится значок.

Удаление: `sudo sh uninstall.sh`.

## Как устроено

| Часть | Где | Что делает |
|---|---|---|
| `SnachalaDeloDaemon` | `/Library/PrivilegedHelperTools/ru.snachaladelo.daemon`, launchd, root | хранит задачи, проверяет все правила, пишет свой раздел в `/etc/hosts`, раз в 2 с закрывает запрещённые приложения |
| `SnachalaDelo` | `/Applications/Сначала дело.app`, LaunchAgent | значок в строке меню, окно задач, настройки |
| Связь | `/var/run/ru.snachaladelo.sock` | JSON-строка запрос → JSON-строка ответ |

Данные: `/Library/Application Support/SnachalaDelo/state.json` (принадлежит root, руками не поправить).
Лог службы: `/var/log/snachaladelo.log`.

Правила проверяет служба, а не окно, поэтому выход из приложения ничего не открывает:
- задача блокирует, если до дедлайна < 24 ч или он прошёл;
- закрытие — удержание кружка 2 с;
- удаление — через 30 с, можно отменить;
- перенос: первый — куда угодно, дальше — не дальше чем на сутки от текущего момента (сдвиг раньше — всегда);
- передышка 15 минут, один раз в календарный день;
- пока есть срочные задачи, из списков сайтов и приложений можно только добавлять.

## Известные пределы

- Уже открытая вкладка с видео может доиграть то, что успело загрузиться; новые страницы не откроются.
  У Chrome свой DNS-кэш, блокировка в нём срабатывает в течение ~1 минуты.
- Вместо «экрана со списком дел» на заблокированных сайтах браузер покажет обычную ошибку
  «не удаётся открыть сайт» (подменить HTTPS-страницу без сертификата нельзя).
- Админ Мака может всё удалить. Телефон не блокируется.
